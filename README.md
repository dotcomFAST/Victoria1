# Вікторія Фастовець — адвокат

Сайт-портфоліо адвоката. Статичний сайт без збірки: HTML + CSS + JavaScript.

## Структура

```
index.html        — сторінка (український текст)
styles.css        — стилі, кольори, анімації
script.js         — перемикач мов UA/EN, мобільне меню, анімації появи
images/           — фотографії
textures/         — фонові текстури (травертин, дуб)
```

## Мови

Основна мова — українська (текст прямо в `index.html`).
Англійські переклади — в об'єкті `EN` у `script.js`, за ключами `data-i18n`.

## Запуск локально

Відкрийте `index.html` у браузері або запустіть простий сервер:

```bash
python -m http.server 5500
```

## Публікація

Підходить для GitHub Pages, Netlify, Vercel тощо — достатньо завантажити файли в корінь репозиторію.
